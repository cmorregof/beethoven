What is an 8-note window?

We read each voice of a score as a melody: one note after another. A window is a run of consecutive notes in one voice. An 8-note window is described by the seven steps between its notes: the interval in semitones (up or down) and a coarse rhythm class for each step. The pitches themselves are not stored, so the same figure in another key counts as the same window.

Short windows are shared by almost everything (scales, arpeggios, repeated notes); long windows are almost never shared. Eight notes is the preregistered compromise: long enough that a shared window is rare across the corpus, short enough that a borrowed theme still produces several of them. The uniqueness curves below show how fast sharing falls as the window grows.

Two ways to ask “is this shared window surprising?”: DF and E

DF (document frequency)
The share of works in the comparison corpus (composers active 1750–1830, excluding the two composers under study) that contain the same window. A small DF means that few other composers of the period use the figure, so finding it in both works is harder to put down to common vocabulary. DF is purely empirical: it counts, it does not model.
E (expected occurrences)
How many times the window would be expected to appear in the later work by chance, according to a statistical model of melodic style (an interpolated n-gram model of the period, mixed with a model of the earlier composer’s own idiom). A small E means that the model finds the figure unlikely, even for a composer writing in that idiom. Because E is a model, we checked that it is calibrated: across held-out works, predicted counts should match observed counts (see “Calibration”).

Why a 5 % false-positive rate?

A threshold on DF or E turns a continuous score into a yes/no flag. We set each threshold on control pairs of string quartets from the same years with no documented relationship: the threshold is the most permissive value that flags at most 5 % of the windows these unrelated pairs share by chance. This fixes the error we can control in advance (false alarms) at the conventional level, before the case of interest is examined, and it was frozen in the preregistration so that it cannot be adjusted after seeing the result.

The 5 % is per shared window, not per pair of works: one pair contributes many correlated windows.

Why a null result here would not be informative

The same thresholds were applied to pairs where a later composer is documented to have modelled a work on an earlier one (for example, a quartet written with a specific earlier quartet as its model). At the 5 % false-positive rate, DF flags only … of the windows those pairs share, and E only …. In other words, modelling in the musicological sense (form, gesture, texture, a reworked theme) leaves almost no trace in exact 8-note matches.

The consequence is stated in the preregistration itself: if the confirmatory test finds no excess of rare shared windows, that will not show that no modelling took place; a method that flags so few modelled windows cannot rule it out. Only a clear excess would be evidence, and then evidence of close, near-literal borrowing.

Sensitivity to literal quotation

Literal borrowing was measured, as an exploratory check, on … pairs of Vivaldi string concertos and their contemporary keyboard arrangements. The DF threshold flags … of the windows such a pair shares (95 % interval …–…), and a contiguous borrowed passage of 10 bars is detected in … of trials. Two cautions: these are an upper bound (exact arrangements of pre-1750 music, scored against thresholds set on later string quartets), and the intervals are optimistic, because the windows of one pair are not independent of each other. Formal adoption of this check is part of the proposed amendment D-43.
